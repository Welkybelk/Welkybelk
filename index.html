How to play
Move W/S forward & back · turn A/D · fire Space or click · scoreboard hold Tab · menu Esc.
Your flashlight cone is all you can see — walls block sight, so watch corners and your blind spots.
Multiplayer (up to 8): one player creates a room and shares the 4-letter code, everyone else hits Join with it, and the lobby shows every player's name and picture before the host starts the match. Players connect directly to each other over WebRTC, so any device on any network can join — no server to run yourself. If a connection can't be made (no internet, or WebRTC is blocked), tabs in the same browser sync instead automatically.
Map maker: paint walls, place spawn pads, save maps, then host them in a room or playtest instantly.

Multiplayer connects players peer-to-peer over WebRTC — open this file (or its hosted link) on any device with an internet connection and join with the room code. Solo play, the map maker, and same-browser tab sync all still work fully offline.
